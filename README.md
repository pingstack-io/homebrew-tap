# Pingstack Homebrew tap

Homebrew packages for [Pingstack](https://pingstack.io) tools.

```bash
brew install pingstack-io/tap/pingstack
```

| Package | What it is |
| --- | --- |
| [pingstack](https://github.com/pingstack-io/pingstack-ping) | Wrap any scheduled job and report it to a Pingstack heartbeat check. |

The package files here are updated automatically by each tool's release
workflow. Please open issues in the tool's own repository.
